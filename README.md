## 📌 Overview

**SafeSpeak** is an AI-powered web application designed to identify and analyze toxic content across multiple languages.

The platform aims to support safer digital communication by combining Natural Language Processing (NLP), Machine Learning, model evaluation, and responsible AI principles.

Beyond toxicity classification, SafeSpeak emphasizes transparency, fairness, explainability, and ethical considerations in automated content moderation.

## 🎯 Objectives

- Detect toxic and potentially harmful textual content across multiple languages.
- Explore different Machine Learning model configurations.
- Evaluate model performance using relevant classification metrics.
- Identify potential biases and fairness issues.
- Promote transparency and responsible AI practices.
- Provide technical documentation and ethical guidelines.

## ✨ Key Features

### 🌍 Multilingual Toxicity Detection
Analyze textual content and identify potentially toxic language across supported languages.

### 🧠 Multiple AI Model Levels
The platform presents four model levels:

- **Bronze Model**
- **Silver Model**
- **Gold Model**
- **Platinum Model**

Each level provides a framework for exploring model configurations and evaluation approaches.

### 📊 Model Evaluation
Explore model performance through classification metrics and evaluation tools.

### ⚖️ Fairness Audit
Examine potential biases and fairness issues to encourage more equitable AI-based moderation.

### 📚 API Documentation
Integrated technical documentation describing the platform's API structure.

### 🛡️ Ethical AI Framework
An ethics charter and guidelines covering responsible AI development, transparency, and fairness.

## ⚙️ Installation and Setup

### Prerequisites

Make sure you have installed:

- Node.js
- npm
- Git

### 1. Clone the repository

```bash
git clone https://github.com/mouna-gif/SafeSpeakMultilingualToxicityDetection.git
```

### 2. Navigate to the project directory

```bash
cd SafeSpeakMultilingualToxicityDetection
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Build for production

```bash
npm run build
```
